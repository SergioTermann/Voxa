# Voxa v1.3.0

## 中文

- **Windows 界面重做**：深色卡片布局、清晰的语言与状态显示、圆角自动结束开关、独立转写区域，以及显示实际麦克风音量的轻巧听写浮窗。
- **默认双击右 Ctrl 开始 / 完成听写**。每次轻按不超过 0.5 秒，两次间隔不超过 0.65 秒。左 Ctrl、长按、Ctrl+C 等组合键、鼠标操作或切换窗口不会构成有效触发；其他按键正常传递。
- **Ctrl + Alt + Space** 保留为备用；**Ctrl + Alt + Esc** 取消。
- Windows 提供包含运行时的 x64 安装 EXE 和便携 ZIP；macOS 提供 DMG 和 `.app` ZIP。中英文 README 同步更新。

Windows 需要兼容的本机 SAPI 听写引擎。macOS 包未经过 Apple 公证，Windows 包未签名。真实麦克风识别与跨应用输入仍需在目标设备验证。

## English

- **Redesigned Windows interface:** dark cards, clear language and status controls, rounded auto-finish toggle, dedicated transcript area, and a compact dictation preview showing actual microphone levels.
- **Double-tap Right Ctrl to start / finish.** Each tap is under 0.5 seconds, with a gap under 0.65 seconds. Left Ctrl, long holds, Ctrl shortcuts, mouse actions and window changes do not form valid triggers. Other input passes through unchanged.
- **Ctrl + Alt + Space** remains the backup; **Ctrl + Alt + Esc** cancels.
- Self-contained Windows x64 installer and portable ZIP, plus macOS DMG and app ZIP. Chinese and English READMEs updated.

Windows requires a compatible local SAPI dictation engine. macOS packages are not Apple-notarized; Windows packages are unsigned. Live microphone recognition and cross-app insertion require target-device validation.

# Voxa v1.2.0

## 中文

- **macOS**：打开 `Voxa-v1.2.0-macOS-arm64.dmg`，把 **Voxa.app** 拖入 **Applications** 即可安装。也提供包含 `.app` 的 ZIP。
- **Windows**：运行 `Voxa-v1.2.0-Windows-Setup-x64.exe`，支持中文 / 英文安装向导、桌面与开始菜单快捷方式、系统卸载。包含 .NET 运行时，无需管理员权限。另提供便携版 ZIP。
- Windows 新版支持本机语音识别、`Ctrl + Alt + Space` 开始 / 完成、实时预览、停顿后自动输入、`Ctrl + Alt + Esc` 取消和托盘运行。
- README 提供完整的中文、英文版本，附两平台安装、权限、隐私和构建说明。

**要求**：macOS 13+ / Apple Silicon；Windows 10 / 11 x64，需要兼容的本机 SAPI 听写引擎。Win + H 可用并不保证兼容引擎已安装。

macOS 包未经过 Apple 公证，Windows 包未签名，首次打开可能出现系统安全提示。Windows 实际麦克风识别及跨应用输入兼容性仍需在目标设备验证；自动化安装、卸载和启动检查不代替真实听写验收。

## English

- **macOS:** open `Voxa-v1.2.0-macOS-arm64.dmg` and drag **Voxa.app** to **Applications**. A ZIP containing the app is also available.
- **Windows:** run `Voxa-v1.2.0-Windows-Setup-x64.exe`. Includes Chinese / English setup, desktop and Start menu shortcuts, an uninstaller and the .NET runtime. No administrator permission required. A portable ZIP is also provided.
- The new Windows app offers local recognition, `Ctrl + Alt + Space` start / finish, a live preview, automatic insertion after a pause, `Ctrl + Alt + Esc` cancellation, and tray operation.
- Full Chinese and English READMEs document installation, permissions, privacy and builds.

**Requirements:** macOS 13+ on Apple Silicon; Windows 10 / 11 x64 with a compatible local SAPI dictation engine. Working Win + H does not establish engine compatibility.

The macOS package is not Apple-notarized, and the Windows package is unsigned, so first launch may require system approval. Real Windows microphone recognition and cross-app insertion still need target-device validation; automated install, uninstall and startup checks do not replace live dictation tests.
